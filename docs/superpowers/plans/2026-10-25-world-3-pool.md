# World 3 (pool) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Levels 3-1 to 3-10 play from seed chooser to award, matching the original.

**Architecture:** Slices on the existing board code (`crates/pvz/src/board/`), each reimplemented from the ruslan831 decomp with a credit comment and a `TestBoard` test in a new `crates/pvz/tests/world3.rs`. Visual pieces (water) are checked by screenshot.

**Tech Stack:** Rust, Bevy 0.20, the workspace's `sexy` crate; decomp cloned shallow into a temp folder (`grep -a`, GBK files: pipe through `iconv -f gbk -t utf-8 -c`).

**Spec:** `docs/superpowers/specs/2026-10-25-world-3-pool-design.md`

## Global Constraints

- Never commit or push (project rule in `agents.md`); leave changes in the working tree. Steps below that say "checkpoint" mean run the verification only.
- Line endings LF; don't touch `readme.md`.
- Reimplement, don't transcribe the decomp; credit the function in a comment (`// Behaviour per ruslan831 decomp, Board::X`).
- `cargo test --workspace` and `cargo clippy --workspace --all-targets` clean after every task.
- Update `agents.md` and `docs/todo.md` when a task changes what's ported.
- Tests use `test_board!("3-1")` style helpers in `crates/pvz/tests/mod.rs` (`tick`, `ticks`, `run_until`, `zombie`, `plant`, `with_waves`); they skip without the game pak.

## Review Focus

- A land plant on a water square without a lily pad is refused (and one on the lily pad works) — pool planting rules.
- A zombie that isn't a swimmer never spawns in a water row, in any wave (not only the first five).
- A zombie that reaches the house in a pool row ends the level at the right position (not the day-lawn y).
- A pool row gets the pool cleaner only if bought (else an ordinary mower that sinks); the cleaner runs once.
- Finishing 3-x never leaves the player on a level whose award is missing.
